# **OWASP Juice Shop Security Assessment**

This web application security assessment project was conducted in a controlled laboratory environment, with OWASP Juice Shop being cloned and deployed on Kali Linux

### **Activities**

* Deployed and configured OWASP Juice Shop
* Identified and validated web application vulnerabilities
* Assessed security risks and potential impact
* Produced remediation recommendations
* Documented findings in a formal report and presented a live demonstration

### **Technologies**

* Kali Linux
* Burp Suite
* Semgrep
* OWASP ZAP
* OWASP Juice Shop

### **Skills**
* Web Application Security
* Vulnerability Assessment
* Risk Analysis
* Security Reporting
